# Prompt Lab

Учебное React-приложение для изучения техник промпт-инжиниринга, создания собственных шаблонов и обмена ими.

> Проект выполнен как итоговая работа по дисциплине «Разработка интерфейса пользователя».

## Возможности

- каталог из шести техник с отдельными страницами;
- каталог публичных шаблонов;
- поиск, категории, сортировка и избранное;
- копирование текста промпта;
- демонстрационная авторизация и защищённый кабинет;
- создание, редактирование и удаление собственных шаблонов;
- отправка локальных изменений на сервер и получение ссылки на опубликованный шаблон;
- скрытие приватных шаблонов от гостя и других демонстрационных пользователей в интерфейсе и Mock API;
- `PromptEditor` с безопасным предпросмотром и подсветкой синтаксиса;
- Mock REST API на `json-server` и локальный fallback;
- адаптивная вёрстка и поддержка доступности;
- динамическая загрузка страниц через `React.lazy`.

## Стек

React 18, TypeScript, Vite, React Router, JSON Server, Vitest, React Testing Library и Playwright.

## Запуск

```bash
npm install
npm run api
```

Во втором терминале:

```bash
npm run dev
```

Интерфейс откроется на `http://localhost:5173`, Mock API — на `http://localhost:3001`.

Демонстрационный вход:

```text
Email: student@example.com
Пароль: 123456
```

Также принимается любой корректный email и пароль длиной от шести символов.

## Доступность

- семантические области страницы;
- skip-link к основному содержимому;
- связанные `label`, `aria-invalid` и `aria-describedby`;
- сообщения с `role="alert"` и `role="status"`;
- видимый фокус и управление клавиатурой;
- настоящие кнопки вместо кликабельных `div`;
- понятные названия кнопок избранного;
- достаточный контраст и адаптивность;
- поддержка `prefers-reduced-motion`;
- русский язык документа (`lang="ru"`).

Подробный чек-лист: [`docs/accessibility.md`](docs/accessibility.md).

## Локальные изменения и обмен ссылками

- При недоступном сервере создание/редактирование сохраняет локальную копию и показывает сообщение «Сохранено только в этом браузере». Галочка публичности задаёт желаемый статус, но сама по себе не отправляет локальную копию другим пользователям.
- В кабинете нажмите «Отправить на сервер». При ошибке копия остаётся в браузере, можно повторить отправку. После успешной отправки старая локальная копия удаляется.
- Для публичного серверного шаблона появляется «Получить ссылку». Приложение проверяет публикацию и показывает поле со ссылкой. Приватные шаблоны передать этой кнопкой нельзя.
- При ошибке удаления серверного шаблона отображается сообщение, карточка остаётся. После успешного удаления обе копии исчезают.
- Для передачи ссылки другому человеку фронтенд и API должны быть доступны ему. Адрес `localhost` предназначен для проверки на своём компьютере.

## Особенности учебной реализации

Авторизация упрощена и хранится в `localStorage`. Mock API (`server.cjs` на базе `json-server`) использует заголовок `X-Demo-User` для учебной идентификации: проверяет автора при изменении/удалении и скрывает приватные записи при чтении. Это не настоящая проверка личности: заголовок можно подделать. Для реального сервиса нужны серверные сессии и настоящая аутентификация; конфиденциальные данные в эту демонстрацию помещать не следует.

Без API доступны резервный каталог и локальные черновики; обмен новыми шаблонами между браузерами требует общего API. Версии зависимостей в этом исправлении не обновлялись: ранее обнаруженные предупреждения `npm audit` остаются отдельной задачей.
