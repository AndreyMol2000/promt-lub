# Подготовка к публикации

1. Разместите исходники в доступном преподавателю Git-репозитории.
2. Запустите API командой `npm run api` на сервере с Node.js. Переменная `PORT` задаёт порт (по умолчанию 3001). Для сохранения изменений между перезапусками файл `db.json` должен находиться на постоянном диске; несколько экземпляров такого файлового Mock API одновременно не запускайте.
3. Для фронтенда задайте `VITE_API_URL` равным общедоступному HTTPS-адресу этого API без завершающего слеша. Пример локальной настройки есть в `.env.example`. Значение встраивается во время сборки.
4. Выполните `npm run build` и разместите содержимое `dist` на статическом хостинге. Настройте возврат `index.html` для неизвестных путей фронтенда: React Router должен обрабатывать `/templates/:id` и другие страницы при прямом открытии.
5. В другом браузере проверьте: открытие и обновление вложенной страницы; вход; создание публичного шаблона; его ссылку без входа; недоступность приватного шаблона; изменение и удаление после перезагрузки.
6. Повторите Lighthouse по опубликованному адресу, сохраните отчёт и замените заглушку демо в README.

Публикация только `dist` без общего API позволяет демонстрировать интерфейс и локальные черновики, но не обмен новыми шаблонами между устройствами.

API учебный: заголовок `X-Demo-User` не заменяет настоящую аутентификацию. Настоящая безопасность аккаунтов не входит в эту mock-реализацию.
